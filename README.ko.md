# premiere-xml

**JSON 컷 목록 → 프리미어 프로가 가져가는 타임라인.** 프리미어를 띄우지 않고, 스크립팅도
쓰지 않고, 딸린 라이브러리도 없습니다. 가져오기 할 파일 하나를 글자로 찍어 냅니다.

(영어판: [README.md](README.md))

```console
$ premiere-xml cutlist.json -o episode_12.xml
episode_12.xml
  episode_12 - 30 fps drop-frame
  2 video / 4 audio clips  (V1 2)  72.52s, 2174 frames
```

프리미어에서 **파일 → 가져오기**. 컷이 차례대로 붙은 시퀀스가 생깁니다. 소리도 붙어 있고
마커도 제자리에 있습니다.

## 왜 만들었나

편집 결정을 다른 데서 만들었다면 — 받아쓰기, 무음 탐지, 표, 혹은 LLM — 그걸 **프리미어 안으로
넣는 일**이 남습니다. 길이 넷인데 셋이 막혀 있습니다.

| | |
|---|---|
| ExtendScript / UXP | 프리미어가 떠 있어야 하고 느리고 잘 깨집니다. 시험하기도 어렵습니다 |
| `.prproj` | gzip 된 제 포맷. 손으로 쓰는 건 연구 과제입니다 |
| 명령줄 | 프리미어 명령줄은 **프로젝트**만 엽니다. `.xml` 은 안 받습니다 |
| EDL | 트랙 여럿·마커·꺼진 클립이 없습니다 |
| **FCP7 XML** | 글자 파일이고, 프리미어가 받아 줍니다 ← 이것 |

## 20줄짜리 스크립트가 아닌 까닭

미디어 파일마다 들어가는 **한 줄** 때문입니다.

경로를 표준 퍼센트 인코딩으로 쓰면 프리미어가 그 파일을 못 찾습니다. 클립이 하나면 오프라인
클립으로 끝나지만, 150개면 가져오기가 통째로 깨지면서 이 말만 뜹니다.

> 프로젝트가 손상되어 열 수 없습니다.

XML 은 멀쩡하고 미디어도 디스크에 있습니다. 경로 이야기는 한마디도 없습니다. 하루를 쓰고 나서
**프리미어가 제 손으로 내보낸 XML** 을 받아 글자 단위로 맞대 보고 알아냈습니다.

규칙은 넷이고, 세 번째가 함정입니다.

1. 드라이브 콜론을 바꾼다 — `C:` → `C%3a`
2. 16진은 **소문자** — `%3A` 가 아니라 `%3a`
3. `( ) [ ] & ~ ! $ ' * + , ; = @ _ - .` 는 **안 바꾼다**
   — `urllib.parse.quote` 가 기본으로 괄호를 바꿉니다. 경로 안의 `%28` 이 바로 그 원인이었습니다
4. 공백은 `%20`, 한글은 UTF-8 퍼센트 인코딩

[`src/premiere_xml/pathurl.py`](src/premiere_xml/pathurl.py) 입니다. 스무 줄에 긴 주석이
붙어 있습니다. 이 저장소에서 하나만 가져가신다면 그 파일입니다.

하나 더 — **29.97 과 30 은 틀려도 오류가 안 납니다.** FCP7 은 정수 timebase 와 NTSC 깃발로
적어서 29.97 이 "30인데 NTSC" 가 됩니다. 잘못 적으면 조용히 밀립니다. 13분이면 0.8초쯤.

## 컷 목록

값은 전부 **초**입니다. 프레임 계산은 안에서 합니다. 자세한 표는 영어판 README 를 보세요.

- `sources` 의 `dur` 은 **실제 길이(초)**. out 이 파일 끝을 넘으면 프리미어가 거부하므로 여기서 잘라 냅니다
- V1 컷은 **적은 차례대로 빈틈없이** 붙습니다. `track` 이 2 이상이면 `at`(시퀀스 위 시작 초)이 있어야 합니다
- `enabled: false` 면 꺼진 채로 들어갑니다 — 안 쓴 테이크를 버리지 않고 남겨 둘 때 씁니다
- 조용히 틀리는 두 가지는 **예외로 올립니다**: 없는 `src`(빈 시퀀스가 됩니다)와 V1 위에서 빠진 `at`(전부 0초에 쌓입니다)

## 하는 것 / 안 하는 것

**합니다** — 원본 여럿 · 트랙 여럿 · V1 자동 이어붙이기 · 위 트랙 자리 지정 · 꺼진 클립 ·
영상만 올리기 · A1/A2 스테레오 · 영상·소리 묶기 · 시퀀스 마커(점·범위) · 드롭/논드롭.

**안 합니다** — 효과·전환·속도·키프레임·색보정·중첩·자막. 컷만 놓습니다.
자막은 따로입니다. `.srt` 를 가져와 시퀀스에 끌어다 놓으면 됩니다.

## 어디까지 확인했나

- 프리미어 프로 25.x · 26.x, 윈도
- 잘 생긴 XML 인지가 아니라 **실제 가져오기**로. 원본 둘에 걸친 92컷 9분짜리 시퀀스 +
  V2 에 꺼 둔 클립 65개 + 마커 7개가 전부 온라인·제 프레임에 들어갔습니다
- 공백·괄호·대괄호·한글이 섞인 경로

안 재 본 것: 맥 · UNC 경로(`\\서버\공유`) · 다빈치/파이널컷 가져오기
